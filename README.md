# Fretwise

Guitar chord shapes, neck maps and song sheets. One web app (`web/`) that runs on iPad (installed from Safari) and inside a small Android shell (`android/`).

- Type any chord symbol to see every playable shape on the neck, ranked, with CAGED forms, barres, triads and jazz voicings (drop 2, drop 3, shells).
- Songs in ChordPro with transpose, capo, chord charts, auto-scroll; paste chords-over-lyrics and it converts.

Run the tests with `node tests/engine.mjs` and `node tests/songs.mjs`.
